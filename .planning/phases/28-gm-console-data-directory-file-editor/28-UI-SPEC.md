# Phase 28 — UI Design Contract

> Visual and interaction contract for the GM Console Data Directory File Editor.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — Ant Design 6.1 + custom CSS variables |
| Preset | not applicable |
| Component library | Ant Design 6.1 (`antd`) + `@ant-design/icons` 6.1 |
| Icon library | `@ant-design/icons` — `FolderOutlined`, `FileOutlined`, `FolderOpenOutlined`, `FolderFilled`, `SaveOutlined`, `CodeOutlined` (or `FileTextOutlined`) for ViewRail entry |
| Font | `'Share Tech Mono', 'Cascadia Code', 'Courier New', monospace` (project standard, source: STYLE_GUIDE.md) |

**New dependency required:** `@monaco-editor/react` (not yet in package.json). Add before implementation. Theme: `vs-dark` (Monaco built-in, no custom theming this phase).

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tree node icon-label gap, status dot margins |
| sm | 8px | Filter input internal padding, file tree node padding, editor toolbar button gaps |
| md | 16px | Tree panel internal padding (horizontal), editor toolbar height padding |
| lg | 24px | Section padding within the split view |
| xl | 32px | Not used in this phase |
| 2xl | 48px | Not used in this phase |
| 3xl | 64px | Not used in this phase |

Exceptions:
- **Tree panel width**: 272px fixed (between the 250–300px decision range — source: CONTEXT.md D-01, exact value: Claude's discretion, chosen 272px for 8-point alignment)
- **ViewRail button**: 32px × 32px circular (matches existing ViewRail buttons exactly — source: ViewRail.css)
- **Editor toolbar height**: 40px (matches 8-point scale, provides enough room for breadcrumb + save button row)
- **Filter input height**: 32px (Ant Design `size="small"` default, acceptable exception)

## Typography

All typography uses the project monospace font stack: `'Share Tech Mono', 'Cascadia Code', 'Courier New', monospace`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body (tree node labels, breadcrumb) | 12px | 400 | 1.5 |
| Label (section headers, editor toolbar path) | 11px | 400 | 1.4 |
| Heading (panel section titles, error banner headline) | 13px | 600 | 1.4 |
| Editor content | Monaco editor default (14px, managed by Monaco internally) | n/a | n/a |

Notes:
- 12px body matches existing GM Console patterns (DocumentsPanel uses 12px, 10px labels — source: DocumentsPanel.tsx)
- Letter-spacing: 1px on ALL-CAPS labels (project standard — source: STYLE_GUIDE.md)
- ALL-CAPS for: section labels, unsaved indicator text, save button label, error banner label
- Sentence case for: file names, directory names, error message body, filter placeholder

│  [STANDBY btn]   │  │              │  ┌─────────────────┐  │  │
│  [BRIDGE btn]    │  │  [filter]    │  │ Toolbar (40px)  │  │  │
│  [ENCOUNTER btn] │  │  [FileTree]  │  │ path + save btn │  │  │
│  ─────────────── │  │              │  ├─────────────────┤  │  │

CSS class: `gm-file-editor-view` (NOT `file-editor-view` — collision guard, per MEMORY.md CSS class collision rule)

### Tree Panel (272px fixed, full height, scrollable)

- Background: `#111e1e` (`--color-bg-panel`)
- Right border: 1px solid `#2a4040` (`--color-border-main`)
- Filter input: top of panel, 8px padding all sides, Ant Design `Input` size="small"
  - Placeholder: `FILTER FILES...` (ALL-CAPS, letter-spacing 1px)
  - Icon: `SearchOutlined` left
- File tree: `Ant Design Tree` with `loadData` prop, `showLine={{ showLeafIcon: false }}`
  - Background: transparent
  - Font size: 12px
  - Node icons: `FolderOutlined` / `FolderOpenOutlined` (directories), `FileOutlined` (files)
  - Selected node: teal left border (2px solid `#4a8b8b`), background `rgba(74, 139, 139, 0.1)`
  - Expanded directory icons: teal (`#4a8b8b`)
  - File extension badge: only shown for non-YAML/non-MD files (e.g., `.png`, `.svg`) — Ant Design `Tag` color="default" at 10px

### Editor Toolbar (40px height strip, full editor width)

Left to right:
1. **Breadcrumb** — directory path segments in text-secondary (`#4a7070`) + file name in text-primary (`#7ab8b8`)
   - Separator: ` / ` in text-muted (`#2a4a4a`)
   - Dirty state: file name color switches to amber-dim (`#8b7355`), modified dot `●` prepended (8px, amber `#c9a050`)
2. **[spacer — flex: 1]**
3. **Save button** — Ant Design `Button` type="default", size="small"
   - Label: `SAVE` (ALL-CAPS, letter-spacing 1px)
   - Icon: `SaveOutlined` left
   - Default state: teal border (`#4a8b8b`), teal text (`#4a8b8b`), transparent bg
   - Dirty state (unsaved changes): amber border (`#c9a050`), amber text (`#c9a050`)
   - Success flash: background `rgba(42, 90, 42, 0.3)` + border `#2a5a2a` for 150ms then returns to dirty/clean state
   - Disabled: when file is not YAML or MD (read-only files)
   - Tooltip: `"Save (Ctrl+S)"` on hover

Toolbar strip background: `#0d1616` (`--color-bg-panel-dark`)
Toolbar bottom border: 1px solid `#1e3333` (`--color-border-subtle`)
Toolbar horizontal padding: 16px left, 8px right

### Error Banner (conditional — shown above Monaco, below toolbar)

- Shown: when PUT /api/gm/data/{path} returns validation error
- Hidden: on new keystroke (reset dirty state clears it), or on next successful save
- Auto-dismiss: 8 seconds (then hidden, does NOT save)
- Height: auto (wraps content), min 40px
- Background: `rgba(192, 57, 43, 0.12)`
- Border: 1px solid `#8b2020`, bottom only
- Layout: row — `ExclamationCircleOutlined` icon left (16px, `#c0392b`) + message text
- Headline: `VALIDATION ERROR` (11px, weight 600, `#c0392b`, ALL-CAPS, letter-spacing 1px)
- Body: backend error message verbatim (12px, weight 400, `#7ab8b8`)
- Padding: 8px 16px

### Monaco Editor (fills remaining height after toolbar + optional error banner)

- Theme: `vs-dark` (Monaco built-in)
- Language detection by extension:
  - `.yaml` / `.yml` → `yaml`
  - `.md` → `markdown`
  - All other text files → `plaintext`, `readOnly: true`
- Options: `minimap: { enabled: false }`, `scrollBeyondLastLine: false`, `wordWrap: 'on'` for markdown, `wordWrap: 'off'` for yaml
- Font: `'Cascadia Code', 'Courier New', monospace`, size 14px (Monaco fontFamily override)
- Width: 100%, Height: 100% (flex fill)
- Ctrl+S: captured via Monaco `addCommand(monaco.KeyMod.CtrlCmd | monaco.KeyCode.KeyS, () => handleSave())`

### Non-Editable File Panel (replaces Monaco when file is image or binary)

- Shown when selected file is not YAML, MD, or plaintext
- Layout: centered column, full editor area
- Images (`.png`, `.jpg`, `.svg`, `.gif`, `.webp`):
  - `<img>` tag, max-width 100%, max-height 80%, object-fit contain
  - Background `#080e0e`
  - File name caption below: 12px, text-secondary
- Binary / unknown:
  - Icon: `FileOutlined` at 48px, color text-muted (`#2a4a4a`)
  - Message: `BINARY FILE — CANNOT EDIT` (13px, weight 600, text-muted, ALL-CAPS, letter-spacing 1px)
  - Sub-message: file path, 11px, text-muted

### Empty State (no file selected)

- Shown when view mounts and no file is selected
- Centered in the editor area
- Icon: `FolderOpenOutlined` at 48px, color text-muted (`#2a4a4a`)
- Heading: `SELECT A FILE` (13px, weight 600, text-muted, ALL-CAPS, letter-spacing 1px)
- Body: `Browse the data directory and select a YAML or Markdown file to edit.` (12px, text-muted)

### ViewRail Entry

- Position: bottom of view list, separated by the existing `view-rail__separator` div inserted below ENCOUNTER button
- Icon: `CodeOutlined` from `@ant-design/icons` (represents file/code editing)
- Tooltip: `"File Editor"` (right placement, matches other ViewRail tooltips)
- Key: `FILE_EDITOR` (new GMViewType enum value)
- Active state: existing `view-rail__btn--active` style (blue `#1668dc` bg — do NOT change)
- DISPLAY button: disabled when `gmView === 'FILE_EDITOR'` — add a `disabled` prop check in ViewRail; disabled state: `opacity: 0.3`, `cursor: not-allowed`

## Interaction States

### File Tree

| State | Visual |
|-------|--------|
| Node hover | Background `rgba(255,255,255,0.04)` |
| Node selected | Background `rgba(74,139,139,0.1)`, left border 2px solid `#4a8b8b` |
| Directory loading (after expand click) | Ant Design Tree built-in spinner |
| Filter active (text in filter box) | Only matching nodes visible; non-matching hidden via `filterTreeNode` prop |

### Save Button

| State | Visual |
|-------|--------|
| No file open | Disabled, opacity 0.3 |
| File open, clean (saved) | Teal border + teal text, opacity 0.7 |
| File open, dirty (unsaved changes) | Amber border (`#c9a050`) + amber text, opacity 1.0 |
| Saving (in-flight PUT request) | Ant Design `loading` prop on Button, spinner replaces icon |
| Save success | 150ms green flash (`rgba(42,90,42,0.3)` bg, `#2a5a2a` border), then returns to clean state |
| Save error | Error banner appears above Monaco; button returns to dirty (amber) state |
| Read-only file | Hidden (not rendered) |

### Unsaved Changes Indicator (modified dot)

- Rendered inline in toolbar breadcrumb, left of filename
- Character: `●` (U+25CF BLACK CIRCLE)
- Size: 8px
- Color: `#c9a050` (amber)
- Visible only when file is dirty

### localStorage Persistence

- Key: `janus_file_editor_last_path`
- Value: last successfully-opened file path (relative to data/)
- Restore on mount: attempt to re-open the last file; silently ignore if path no longer exists

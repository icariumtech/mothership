<objective>
Add the server-side core of AI map editing to `core/views/gm_data.py`: (1) a pure resolver
`_resolve_map_element(data, query)` that scans every deck's `rooms` and `doors` and returns
matching elements by exact id → slugified label → glob/prefix → fuzzy; (2) a new endpoint
`api_gm_data_map_edit` that resolves a `target`, then applies one of `set` (deep-merge fields),
`add_poi` (append to the room's `poi` list), or `remove_poi` (by label or index), writing the
file atomically and broadcasting `data-changed`. Register the route ahead of the
`data/<path:filepath>` catch-all. Add Django tests.

Purpose: this is the backend contract the MCP tools (Plan 30-03) wrap. The endpoint must do all
read-modify-write server-side so the AI never loads the whole deckplan to change one element.

Output: `_resolve_map_element` helper, `api_gm_data_map_edit` view, URL route, tests.
</objective>

  <action>
    Add a pure helper (no I/O) `_resolve_map_element(data: dict, query: str) -> dict` that returns:
      {"matches": [ {"id","kind","label","deck"} , ... ], "strategy": "<how matched>"}

    Build an index of every element first: iterate data.get('decks', []); for each deck d,
    for each room in d.get('rooms', []) emit {id: room['id'], kind: 'corridor' if room.get('type')=='corridor' else 'room',
    label: room.get('name') or room['id'], deck: d.get('id')}; for each door in d.get('doors', []) emit
    {id: door['id'], kind: 'door', label: ' / '.join(door.get('rooms', [])) or door['id'], deck: d.get('id')}.
    Skip elements without an 'id' (defensive).

    Then match query against that index, returning the FIRST strategy that yields >=1 match:
      1. exact   — element id == query
      2. slug    — slugify(label) == slugify(query), where slugify = lower(), strip, spaces/hyphens -> '_'
      3. glob     — fnmatch.fnmatch(id, query) (supports 'coolant_tanks*'); also try fnmatch on slug(label)
      4. fuzzy    — difflib.get_close_matches(slug(query), [slug ids], n=8, cutoff=0.6) mapped back to elements
    Record which strategy matched in the returned "strategy". If nothing matches, return matches=[] with
    strategy="none" plus a "suggestions" list = get_close_matches over all ids (n=5, cutoff=0.4).

    Keep it deterministic: preserve deck/room/door document order in the matches list.
  </action>

    Add `@csrf_exempt def api_gm_data_map_edit(request, filepath)` accepting POST (and a no-op GET that
    rejects). Body JSON fields:
      target     (str, required) — element reference, run through _resolve_map_element
      set        (dict, optional) — fields to deep-merge into the resolved element
      add_poi    (dict, optional) — a POI mapping to append to the resolved ROOM's poi list
      remove_poi (str|int, optional) — POI label (str) or 0-based index (int) to remove from the room

    Flow:
      1. Path-traversal guard + 404 if file missing (same idiom as api_gm_data_file).
      2. Load YAML; 400 if not a mapping or invalid YAML.
      3. res = _resolve_map_element(data, target).
         - 0 matches -> 404 {"error","suggestions"}.
         - >1 matches -> 409 {"error":"ambiguous","candidates": res["matches"]} and DO NOT write.
      4. Exactly one match -> locate the live element object inside `data` (re-find by id so we mutate
         the real dict, not a copy). Track deck + element.
      5. Exactly one of set/add_poi/remove_poi must be provided -> else 400 "exactly one operation required".
         - set: element.update(_deep_merge(element, set_dict)) i.e. replace element contents with the merge.
         - add_poi: only valid when kind != 'door' -> element.setdefault('poi', []).append(add_poi); else 400.
         - remove_poi: only valid when kind != 'door'; resolve target POI by int index or by matching
           poi['label']==value; 404 if not found; del from list. If list becomes empty, leave [] (or drop key — discretion).
      6. yaml.dump + safe_write_yaml(target_path, ...) (reuse existing dump kwargs).
      7. announce_generic('data-changed', {'path': filepath, 'action': 'map-edit', 'element': <id>, 'op': <op>}) in try/except.
      8. Return 200 {"ok": True, "element": <id>, "kind": <kind>, "op": <op>, "deck": <deck>}.

    Register the route in core/urls.py ABOVE the api/gm/data/<path:filepath> catch-all:
      path('api/gm/data-map-edit/<path:filepath>', views.api_gm_data_map_edit, name='gm_data_map_edit')

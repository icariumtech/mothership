<objective>
Build the pure, DOM-free core of the deckplan editor: the YAML CST parsing layer
(`useDeckplanModel.ts` — id→range map + deck→MapPreview adapter) and the surgical
edit-range builders (`deckplanYamlEdits.ts` — `buildPositionEdit`, `buildAddPoiEdit`),
plus their vitest unit tests and a shared fixture. These are the contracts that Plan 04
wires into Monaco; defining and testing them first (interface-first) lets Plan 03's
renderer and Plan 04's wiring consume stable, verified function signatures.

Purpose: The genuinely-new logic in this phase is exactly these pure functions
(per RESEARCH "Key insight"). Isolating + unit-testing them removes the highest-risk
surface (deck-scoped id collisions, mid-edit parse errors, surgical range math) before any
UI wiring exists. vitest IS installed (`pnpm test` → `vitest run`), so no Wave 0 runner
install is needed.

Output: Two pure-function modules, a YAML fixture, and two passing vitest test files.
</objective>

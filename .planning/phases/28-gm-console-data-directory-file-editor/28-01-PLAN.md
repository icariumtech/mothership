    Change 2 — Return shape: Replace the current files-only list (bare strings) with a combined list of files AND directories. Each element is an object with two fields: "name" (string, basename only) and "type" ("file" or "directory"). Sort the array: directories first (alphabetically), then files (alphabetically). No recursion — only immediate children of the requested directory. Filter out entries that are neither files nor dirs (e.g., broken symlinks) using entry.exists().

    The new return shape: [{"name": "campaign", "type": "directory"}, ..., {"name": "janus.yaml", "type": "file"}]

    Use target_dir.iterdir() with entry.name for name and ("directory" if entry.is_dir() else "file") for type.

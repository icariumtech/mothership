    Imports:
    - `import { useRef, useState, useCallback } from 'react';`
    - `import './MapPlaybackControls.css';`

    Export `MapPlaybackControlsProps` interface with these four fields (copy the JSDoc comments from 25-UI-SPEC.md):
    - `isPlaying: boolean`
    - `onTogglePlay: () => void`
    - `showScrub: boolean`
    - `onScrubDelta?: (deltaX: number) => void`

    Export `MapPlaybackControls: React.FC<MapPlaybackControlsProps>`. Internal refs/state:
    - `const isDraggingRef = useRef(false)`
    - `const lastXRef = useRef(0)`
    - `const trackRef = useRef<HTMLDivElement>(null)`
    - `const cumulativeXRef = useRef(0)` — track-clamped cumulative pixel offset for thumb
    - `const [thumbX, setThumbX] = useState(0)` — cosmetic thumb left position in pixels

    Drag handlers (use `useCallback`):
    - `handlePointerDown(e: React.PointerEvent<HTMLDivElement>)`:
      - early-return if `!onScrubDelta` or `isPlaying`
      - `e.currentTarget.setPointerCapture(e.pointerId)`
      - `isDraggingRef.current = true`
      - `lastXRef.current = e.clientX`
    - `handlePointerMove(e: React.PointerEvent<HTMLDivElement>)`:
      - early-return if `!isDraggingRef.current` or `!onScrubDelta`
      - compute `deltaX = e.clientX - lastXRef.current`
      - `lastXRef.current = e.clientX`
      - call `onScrubDelta(deltaX)`
      - update cosmetic thumb: read `trackRef.current?.getBoundingClientRect().width` (fallback 300), update `cumulativeXRef.current` clamped to `[0, trackWidth]`, then `setThumbX(cumulativeXRef.current)`
    - `handlePointerUp(e: React.PointerEvent<HTMLDivElement>)`:
      - `e.currentTarget.releasePointerCapture(e.pointerId)`
      - `isDraggingRef.current = false`

    JSX (single root div):
    ```
    <div className="map-playback-controls">
      <button
        className={`map-playback-controls__btn${!isPlaying ? ' map-playback-controls__btn--paused' : ''}`}
        aria-label={isPlaying ? 'Pause animation' : 'Play animation'}
        onClick={onTogglePlay}
        type="button"
      >
        {isPlaying ? '⏸' : '▶'}
      </button>
      {showScrub && (
        <div
          ref={trackRef}
          className={`map-playback-controls__scrub${isPlaying ? ' map-playback-controls__scrub--disabled' : ''}`}
          aria-disabled={isPlaying}
          aria-label="Scrub orbital time"
          role="slider"
          onPointerDown={isPlaying ? undefined : handlePointerDown}
          onPointerMove={isPlaying ? undefined : handlePointerMove}
          onPointerUp={isPlaying ? undefined : handlePointerUp}
          onPointerCancel={isPlaying ? undefined : handlePointerUp}
          style={{ touchAction: 'none' }}
        >
          <div className="map-playback-controls__scrub-track" />
          {!isPlaying && (
            <div className="map-playback-controls__scrub-thumb" style={{ left: `${thumbX}px` }} />
          )}
        </div>
      )}
    </div>
    ```

    Icons: ⏸ (U+23F8) when playing, ▶ (U+25B6) when paused. aria-labels exactly as in Copywriting Contract: "Pause animation" / "Play animation" / "Scrub orbital time". The component itself owns NO animation state — it only emits callbacks.

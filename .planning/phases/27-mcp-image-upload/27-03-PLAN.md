Upload_image tool interface (from Plan 02):
  filename: str — bare filename, no directory path, no path separators
  content_base64: str — base64-encoded binary content of the image file
  image_type: str — one of: portrait, logo, map, misc
  convert: bool (optional, default true) — portrait only; triggers amber-gradient conversion
  Returns: {saved_path, converted_path?, original_size_bytes}

  portrait → data/campaign/NPCs/images_source/{filename}  (convert=true also writes data/campaign/NPCs/images/{stem}.png)
  logo     → data/campaign/images/logos/{filename}
  map      → data/campaign/images/maps/{filename}
  misc     → data/campaign/images/misc/{filename}

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Button label (PLAY/PAUSE) | 11px | 400 (regular) | 1.0 | Share Tech Mono / Cascadia Code |
| Button icon (▶ / ⏸) | 16px | 400 (regular) | 1.0 | System unicode |
| Scrub tooltip (if shown) | 10px | 400 (regular) | 1.0 | Share Tech Mono / Cascadia Code |
| Letter spacing | — | — | — | 2px on all control text labels |

**Rationale:** Control overlay is a minimal HUD element. Two weights are not needed — a single weight (400) with letter-spacing carries the CRT feel. Icon at 16px is the primary affordance; label at 11px is subordinate.

Source: STYLE_GUIDE.md top-nav text size reference (11px / letter-spacing 3px), CLAUDE.md font stack

## Component Inventory

### MapPlaybackControls (new component)

**Purpose:** Stateless presentational overlay row. Renders inside the map wrapper div (sibling to `<Canvas>`), not inside the R3F scene.

**File:** `src/components/domain/maps/MapPlaybackControls.tsx` + `MapPlaybackControls.css`

**Props interface:**

```typescript
interface MapPlaybackControlsProps {
  /** Whether animation is currently playing */
  isPlaying: boolean;
  /** Toggle play/pause */
  onTogglePlay: () => void;
  /** Whether to show the scrub bar (galaxy map: false, system/orbit: true) */
  showScrub: boolean;
  /** Callback fired during scrub drag with delta in pixels (positive = right/forward) */
  onScrubDelta?: (deltaX: number) => void;
}
```

**Layout structure (one horizontal row):**

```
[ play/pause button ] [ scrub track+thumb ]   ← system/orbit maps
[ play/pause button ]                          ← galaxy map only
```

**DOM structure:**

```html
<div class="map-playback-controls">
  <button class="map-playback-controls__btn" aria-label="Pause animation | Play animation">
    <!-- ▶ or ⏸ -->
  </button>
  <!-- only rendered when showScrub=true -->
  <div class="map-playback-controls__scrub" aria-disabled="true|false">
    <div class="map-playback-controls__scrub-track">
      <div class="map-playback-controls__scrub-thumb" />  <!-- hidden when playing -->
    </div>
  </div>
</div>
```

### Overlay Positioning

Overlay pill is `position: absolute; top: 24px; left: 50%; transform: translateX(-50%); z-index: 10` inside the map container div.

The map wrapper divs (`galaxy-map-container`, etc.) are already `position: absolute; width: 100%; height: 100%`, so the overlay inherits correct stacking context.

**Do NOT use `DashboardPanel` or `CompactPanel`** — those components include headers, scrollable content areas, and chamfer CSS that is excessive for a minimal HUD control. Use a plain `div` with manual CRT pill styling.

Source: CONTEXT.md D-12, D-13; GalaxyMap.tsx layout pattern

## Visual Specification

### Overlay Pill

```
background:  #111e1e (--color-bg-panel)
border:      1px solid #2a4040 (--color-border-main)
clip-path:   polygon(12px 0%, calc(100% - 0px) 0%, 100% 0%, 100% 100%, 0% 100%, 0% 12px)
             — single chamfer top-left only (12px, matching system chamfer size)
padding:     8px 16px
display:     flex
align-items: center
gap:         8px
```

### Play/Pause Button

```
min-width:        44px
min-height:       44px
display:          flex
align-items:      center
justify-content:  center
background:       transparent
border:           1px solid #2a4040
cursor:           pointer

State: playing
  icon:           ⏸  (U+23F8)
  icon color:     #c9a050 (--color-amber)
  border-color:   #2a4040

State: paused
  icon:           ▶  (U+25B6)
  icon color:     #c9a050 (--color-amber)
  border-color:   #c9a050  ← amber border signals scrub is now active

Hover (both states):
  background:     rgba(201, 160, 80, 0.08)  ← very subtle amber glow
  border-color:   #d4b060 (--color-amber-bright)
```

**Button label:** Icon-only (no PLAY / PAUSE text label alongside icon). The icon is self-evident in context and the TV use case benefits from larger touch area without text consuming space. `aria-label` carries the accessible name.

Source: CONTEXT.md "Claude's Discretion" — icon only vs. label is discretion area; icon-only chosen for touch TV context.

### Scrub Bar

```
Outer container (.map-playback-controls__scrub):
  width:          min(300px, calc(100% - 80px))
  height:         44px  ← full touch target height
  display:        flex
  align-items:    center
  cursor:         grab (when paused) | default (when playing)
  user-select:    none

Track line (.map-playback-controls__scrub-track):
  width:          100%
  height:         2px
  background:     #2a4040 (--color-border-main) when playing (disabled)
                  #4a8b8b (--color-teal) when paused (active)
  position:       relative

Thumb dot (.map-playback-controls__scrub-thumb):
  display:        none when playing
  display:        block when paused
  width:          8px
  height:         8px
  border-radius:  50%
  background:     #c9a050 (--color-amber)
  position:       absolute
  top:            50%
  left:           50%  ← starts centered; moves with drag delta clamped to track width
  transform:      translate(-50%, -50%)
```

**Thumb behavior during drag:** Thumb follows pointer X position clamped within track bounds. Visual feedback only — actual orbital offset is computed from cumulative drag delta by the parent hook, not from thumb pixel position.

**Drag mechanics:**
- `pointerdown` → capture pointer, record `startX`
- `pointermove` → compute `deltaX = currentX - lastX`, call `onScrubDelta(deltaX)`, update `lastX`
- `pointerup` / `pointercancel` → release pointer capture

No tooltip while dragging. The map itself is the feedback — planet positions update in real-time as the offset accumulates.

Source: CONTEXT.md D-05, D-11; "Claude's Discretion" — tooltip decision; no tooltip chosen (map is the feedback).

| System | Button shows ⏸ amber; scrub visible but grayed, cursor default | Button shows ▶ amber; scrub teal track + thumb, cursor grab |

## Wiring to Existing State

| Map | Play state source | Pause toggle | Scrub delta handler |
|-----|-------------------|--------------|---------------------|
| Galaxy | `useSceneStore(s => s.animations.autoRotate)` | `setAutoRotate(!autoRotate)` | n/a |
| System | local `useState<boolean>` in SystemMap (or passed prop from parent) | local setter | calls `onScrubDelta` → parent hook applies radians per pixel |
| Orbit | local `useState<boolean>` in OrbitMap | local setter | same pattern |

Galaxy uses existing `sceneStore.animations.autoRotate` (already wired in `GalaxyControls.tsx`). System and orbit orbit-pause state is local React state per CONTEXT.md D-08.

Source: CONTEXT.md D-08, D-09; `src/stores/sceneStore.ts`

## Overview

This milestone built the GM tool from its existing 3D map + bridge skeleton into a fully-featured interactive command center: campaign logs, ship status tracking, encounter tokens, NPC portrait displays, real-time SSE push architecture, grid-based encounter maps, redesigned GM console, atmospheric CRT animations, a reworked Bridge STATUS tab with resource tracking, and a restructured data directory.

## Milestone Summary

**Key Decisions:**

- SSE over WebSockets: named-event SSE fan-out with per-listener queues; simpler than WebSockets, sufficient for tabletop pace
- Grid maps over node-graph: wall-segment algorithm with edge-count exclusion; interior edges suppressed automatically
- View-driven GM Console: purely local GMViewType state; DISPLAY button is the only action that reaches the server
- Flat location directory: self-registration into orbit maps eliminates galaxy tree traversal for non-celestial locations
- Per-entity character files: glob-based loading with ID uniqueness checks; better for manual editing and AI token cost

**Issues Resolved:**

- ActiveView SQLite polling bottleneck — replaced with in-memory SSE push (Phase 5)
- GM Console screen real estate — flat tabs replaced with view rail + full-screen areas (Phase 8)
- Port-03 design revert — NPCPortraitOverlay intentionally removed from GM EncounterView post-Phase 11; deviation documented
- Security gaps (api_set_ship_location, api_bridge_selection) — @login_required added / intentionally-public docstring (Phase 20)

**Issues Deferred:**

- UI Audio (AUDI-01..03) — moved to v2; Phase 6 never created
- Player-controlled token movement — out of scope (GM-controlled paradigm)
- Nyquist VALIDATION.md gaps for early phases (01-03) — functional, not formally validated

**Technical Debt Incurred:**

- Phase 18 VERIFICATION.md status: human_needed (3 browser visual checks deferred)
- Phase 17 VERIFICATION.md status: human_needed (1 browser check deferred)
- PORT-03 design-revert: requirement as written no longer exactly satisfied; documented as accepted design decision

<objective>
Consolidate the codebase on `deckplan.yaml` as the sole deckplan map format. Migrate
the last legacy-format location (somnus) to a single `deckplan.yaml`, delete the legacy
`map/`-directory loaders and all fallback branches that depended on them, and update the
canonical schema doc in the same commit.

the alternative `map/manifest.yaml` + per-deck `map/*.yaml` paths so there is exactly one
loader (`load_deckplan()`) and one file shape to render and edit.

Output: Migrated `data/ships/somnus/deckplan.yaml`; pruned `core/data_loader.py`,
`core/views/encounter.py`, `core/views/navigation.py`, `core/payload_builder.py`; updated
`docs/schemas/schema-encounters.md`; a Django regression test.
</objective>

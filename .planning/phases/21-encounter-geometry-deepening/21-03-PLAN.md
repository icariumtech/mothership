  <name>Task 3: Create mapView module</name>
  <action>
Create `src/components/domain/encounter/geometry/mapView.ts`. Export:

```ts
export interface MapView {
  doorPosition(door: Door): SvgPoint;
  doorBounds(door: Door): { center: SvgPoint; width: number; height: number; angle: number };
  roomPolygonPoints(rect: GridRect): string;       // SVG polygon points string
  roomChamferedPolygonPoints(rect: GridRect): string;
  wallEdges(rects: GridRect[]): SvgEdge[];
  labelPosition(room: GridRoom): SvgPoint;
  bbox(rooms: GridRoom[], hull?: HullDef): { originX: number; originY: number; width: number; height: number };
  // pass-through to projection for non-room things:
  project(p: GridPoint): SvgPoint;
  unproject(p: SvgPoint): GridPoint;
  unitSize: number;  // exposed for door slot drawing dimensions
}

export function makeMapView(projection: Projection): MapView;
```

Closure factory pattern: `makeMapView(projection)` captures `projection`, exposes methods that compose `roomGeometry` calls with `projection.project`.

This is the seam. After this lands, the renderer never multiplies by `unitSize` directly — it asks the view.

</task>

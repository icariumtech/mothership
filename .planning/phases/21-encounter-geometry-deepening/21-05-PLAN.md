  <name>Task 1: Create scheduleReveal pure function</name>
  <action>
Create `src/components/domain/encounter/animation/scheduleReveal.ts`. Export:

```ts
export type RevealAnim = 'revealing' | 'hiding';

export interface RevealStep {
  roomId: string;
  anim: RevealAnim;
  delayMs: number;
}

export type CascadeStrategy = 'y-ascending';   // future: 'center-out', 'instant', etc.

export interface ScheduleRevealOpts {
  strategy?: CascadeStrategy;
  baseDelayMs?: number;     // default 50
  staggerMs?: number;        // default 75
  animationDurationMs?: number;  // default 400 — used to compute timer clear delay
}

export function scheduleReveal(
  prev: RoomVisibilityState | undefined,
  curr: RoomVisibilityState | undefined,
  rooms: GridRoom[],
  mapIdentity: string,
  prevMapIdentity: string | undefined,
  opts?: ScheduleRevealOpts,
): RevealStep[]
```

Behavior, lifted from `EncounterMapRenderer.tsx` lines 618–685:

1. If `mapIdentity !== prevMapIdentity`, return `[]` (treat current visibility as new baseline; no animations on map switch)
2. If `prev` or `curr` is undefined, return `[]`
3. Compute diff: rooms transitioning visible→hidden (`hiding`) or hidden→visible (`revealing`)
4. Sort affected rooms by Y-ascending (use `rooms` array's room data; helper to extract Y centroid for rect/circle/polygon — same logic as the existing `getY` closure)
5. For each, compute `delayMs = baseDelayMs + sortIndex * staggerMs`
6. Return the steps; caller will set timers for `delayMs + animationDurationMs + buffer (50ms)` to clear the anim state

This is pure: same inputs → same outputs. No side effects.

<task type="auto">
  <name>Task 3: Create useRoomRevealAnimations hook</name>
  <action>
Create `src/components/domain/encounter/animation/useRoomRevealAnimations.ts`. Export:

```ts
export function useRoomRevealAnimations(opts: {
  visibility: RoomVisibilityState | undefined;
  rooms: GridRoom[];
  mapIdentity: string;
  enabled: boolean;
}): Map<string, 'revealing' | 'hiding'>
```

Implementation requirements:

- If `enabled` is false, return empty Map; run no timers; clean up any existing timers
- Track `prevVisibility` and `prevMapIdentity` in refs
- On change detected, call `scheduleReveal(...)` to compute steps
- For each step, set a `setTimeout` keyed by roomId in a ref'd Map<string, NodeJS.Timeout>
- When a timer fires, remove the room from the anim-state Map
- When re-scheduling for a room that already has an in-flight timer, clear the old timer first (the SSE-echo cancellation case)
- On unmount, clear all timers

The hook returns the current `Map<string, 'revealing'|'hiding'>` as React state.

Do NOT bake `isGM` into the hook — `enabled` is the only policy knob.

</task>

resolver (Plan 30-01) and the AI can address any room, corridor, or door reliably and ids do
not churn on re-export. Rooms/corridors: guarantee unique slug ids with a deterministic numeric
suffix on collision. Doors: derive a readable id encoding both connected rooms where unambiguous,
falling back to the existing `<room>_door_<N>` for exterior (single-room) doors.

independent of the backend (30-01) and can run in parallel.

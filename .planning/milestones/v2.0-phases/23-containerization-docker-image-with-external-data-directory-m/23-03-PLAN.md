Define safe_write_yaml(file_path: Path, content: str) -> None as a module-level helper:
  1. Validate YAML: yaml.safe_load(content) — raises yaml.YAMLError on invalid YAML
  2. Check extension: only allow .yaml and .yml files (reject others with ValueError)
  3. Atomic write: write to temp file in same directory using tempfile.NamedTemporaryFile, then os.replace(tmp_path, file_path)
  Use os.replace (POSIX-atomic rename) — never write directly to the target file.

Function 1 — api_gm_data_list(request):
  GET-only (no @csrf_exempt needed — read-only)
  Query param: ?dir=path (relative to settings.DATA_DIR)
  Validate: resolved target must be inside data_root (same is_relative_to check as write)
  Return: JsonResponse(list of filenames) sorted alphabetically
  404 if directory does not exist; 400 if dir param missing

Function 2 — api_gm_data_file(request, filepath):
  @csrf_exempt decorator (handles both GET and PUT)
  Include docstring: "INTENTIONALLY UNAUTHENTICATED: trust-network model per D-09. Container is self-hosted on homelab, not internet-exposed."
  
  GET: Read file content, return HttpResponse(content, content_type='text/plain; charset=utf-8')
       404 if file does not exist
  
  PUT: Path traversal check FIRST (before any write):
       data_root = Path(settings.DATA_DIR).resolve()
       target = (data_root / filepath).resolve()
       if not target.is_relative_to(data_root): return JsonResponse({'error': 'Path not allowed'}, status=400)
       
       Read request body as string (request.body.decode('utf-8'))
       Call safe_write_yaml(target, content) — catches yaml.YAMLError and ValueError:
         On yaml.YAMLError: return JsonResponse({'error': 'Invalid YAML', 'detail': str(e)}, status=400)
         On ValueError (bad extension): return JsonResponse({'error': str(e)}, status=400)
       
       After successful write, broadcast SSE (in try/except — broadcast failure must NOT roll back the write):
         try:
             broadcaster.announce_generic('data-changed', {'path': filepath, 'action': 'write'})
         except Exception as e:
             logger.warning('SSE broadcast failed after write: %s', e)
       
       Return JsonResponse({'ok': True, 'path': filepath})
  
  405 for other methods

Function 3 — api_gm_session_context(request):
  GET-only (no @csrf_exempt needed)
  Compose from two sources:
    state = get_state()  (in-memory active view store)
    loader = get_loader()
    npcs = loader.load_npcs() or []
    crew = loader.load_crew() or []
    ship_status = loader.load_ship_status() or {}
  Return JsonResponse({'state': state, 'npcs': npcs, 'crew': crew, 'ship_status': ship_status})
  Catch all exceptions with a 500 response and logger.exception

Function 4 — api_gm_data_schema(request):

  Return HttpResponse(content, content_type='text/markdown; charset=utf-8')
  404 if file does not exist

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP request → api_gm_data_file PUT | Unauthenticated write — path and content validation is the only defense |
| filepath URL param → filesystem | User-supplied path must be constrained to data_root |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-03-01 | Tampering | Path traversal on PUT /api/gm/data/{path} | mitigate | Path.resolve() + is_relative_to(data_root) check before any write; extension whitelist (.yaml/.yml only) |
| T-23-03-02 | Tampering | YAML injection / arbitrary Python execution | mitigate | yaml.safe_load() for validation — never yaml.load() without explicit Loader |
| T-23-03-03 | Tampering | Partial write corrupts YAML on crash | mitigate | Atomic write via tempfile.NamedTemporaryFile + os.replace() |
| T-23-03-04 | Information Disclosure | api_gm_session_context exposes all game state | accept | Trust-network model (D-09); endpoint is on homelab local network only; no player-facing exposure |
| T-23-03-05 | Denial of Service | SSE broadcast failure blocks write response | mitigate | broadcast in try/except after write — failure logged, not raised |
</threat_model>

# BLOCKING CONSTRAINTS — Read Before Anything Else

> These are not suggestions. Each constraint below was discovered through failure.
> Acknowledge each one explicitly before proceeding.

- [ ] CONSTRAINT: POI_ROOM_SCOPE — POIs are room-scoped in YAML. buildAddPoiEdit now uses point-in-polygon to find the containing room and inserts there via _buildAddPoiToRoomNodeEdit. Do NOT revert to deck-level insertion as the primary path.
- [ ] CONSTRAINT: DASH_COLUMN_INDENT — items[0].range[0] points to the '{' of a flow map, NOT the '-' dash. Indent must be computed by scanning linePrefix.indexOf('-'). Using firstItemCol-1 gives wrong indent and breaks YAML on second add.
- [ ] CONSTRAINT: POI_EMPTY_KEY — After buildPoiRoomMoveEdit removes the last poi item, the poi: key stays as null value. buildAddPoiEdit must detect this (poi-empty branch) and insert into the existing key, not create a duplicate.
- [ ] CONSTRAINT: GM_HIT_TARGETS — EncounterMapRenderer renders room hit elements in two branches: isGM and !isGM. Any new pointer callback must be added to BOTH branches.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| DECK_LEVEL_POI | buildAddPoiEdit was always inserting at deck level (under doors), not into the clicked room | blocking | Primary path now uses _findRoomForPoint + _buildAddPoiToRoomNodeEdit; deck-level is fallback only |
| DUPLICATE_POI_KEY | When poi-absent ran twice (after a delete left empty poi: key), it inserted a second poi: key causing YAML corruption | blocking | poi-empty branch detects null/empty poi: key and inserts item into it instead of creating new key |
| CRLF_CONTAMINATION | Monaco defaults to CRLF on WSL2/Windows; saving added ^M to every line | blocking | setEOL(0) in onEditorMount + .replace(/\r\n/g,'\n') on save |
| DASH_COL_WRONG | Used firstItemCol (col of '{') as indent for '-'; should be col of '-' | blocking | Scan linePrefix.indexOf('-') from line start to get true dash column |

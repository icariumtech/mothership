- `pointInPolygon(p: Point, poly: Polygon): boolean` — ray-casting test
- `polygonAreaCentroid(pts: Polygon): Point` — shoelace-formula area-weighted centroid
- `polygonBoundaryFromRay(poly: Polygon, origin: Point, angle: number): Point` — generalised version of the existing `getPolygonBoundaryPoint` (ray from arbitrary origin, not just centroid)
- `octagonFromRect(rect: GridRectShape, chamfer: number): Polygon` — 8-point chamfered rect; degenerates to 4 points when chamfer ≤ 0; clamps chamfer to half the smaller dimension

Define local types `Point = { x: number; y: number }` and `Polygon = Point[]`. Do NOT import from `encounterMap.ts` — this module must be domain-free.

`GridRectShape` is local: `{ x: number; y: number; w: number; h: number }`. Don't import the encounter-map `GridRect` here — keeping polygon2d domain-free is the whole point.

Reference the existing implementations in `EncounterMapRenderer.tsx` (lines 115–193 and 286–305) for behavior parity. The renderer-local helpers stay in place for now.

**polygonBoundaryFromRay:**
- ray from centre of unit square at angle 0 → ≈ (1.0, 0.5)
- ray at angle π/2 → ≈ (0.5, 1.0)
- ray from off-centre origin in convex polygon → known intersection

**octagonFromRect:**
- chamfer = 0 → 4 points (degenerate to plain rect)
- 4×4 rect with chamfer = 1 → 8 points, exact coords
- chamfer = 99 (over-large) → clamped to (min(w, h) / 2 - epsilon), still produces 8 valid points

<task type="auto">
  <name>Task 4: Create src/components/domain/encounter/geometry/gridProjection.ts</name>
  <action>
Create the directory `src/components/domain/encounter/geometry/` and file `gridProjection.ts`. Export:

```ts
export interface GridPoint { gx: number; gy: number; }
export interface SvgPoint { x: number; y: number; }

export interface Projection {
  project(p: GridPoint): SvgPoint;
  unproject(p: SvgPoint): GridPoint;
}

export function topDownProjection(opts: { unitSize: number }): Projection;
```

The top-down implementation is trivial multiplication / division by `unitSize`. The interface shape is future-friendly so `isoProjection({ unitSize, tilt, rotation })` can land later without breaking callers.

Do NOT import from `encounterMap.ts` — this is also domain-free (just a coordinate transform). It can later be reused for tokens, hull, POIs, terminals.
  </action>
</task>

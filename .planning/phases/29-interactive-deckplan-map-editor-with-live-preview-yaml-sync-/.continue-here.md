**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| GM_HIT_TARGETS | EncounterMapRenderer renders room hit targets in two branches: isGM (onContextMenu only) and !isGM (pointer handlers only). Adding a new pointer-driven callback for GM requires adding it to BOTH branches — the isGM branch is not a dead path. Discovered when room click-to-jump silently did nothing in GM mode. | blocking | Before wiring any new pointer callback to EncounterMapRenderer, grep for `isGM ?` in the room render functions and confirm the GM branch also has the new handler. |
| POINTERDOWN_GM_BAILOUT | handleRoomPointerDown had `if (isGM) return` before setting roomTapStart — so handleRoomPointerUp always saw null start. Any future early-return in pointer handlers must come AFTER the shared state is recorded. | advisory | Check handleRoomPointerDown/Up for isGM guards before the state-recording line. |
| BACKGROUND_CLICK_FILTER | handleSvgBackgroundClick uses a class-based filter to reject non-background clicks. New SVG layers (hull, vents, future layers) must be added to this filter or they'll create spurious empty-cell POIs. | advisory | After adding any new SVG layer group, add its className to the isBackground check in handleSvgBackgroundClick. |
